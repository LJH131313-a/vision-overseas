# 远见·企业出海助手

面向中国小家电出海业务的合规准备工作台：把**企业研究档案、产品与目标市场登记、法规合规初筛、HS 候选与税费阶段测算、政策新闻雷达、千问辅助建议**连接到一份**可追溯的综合报告**。

纯静态网站（无后端、无数据库、无 API 密钥），可直接部署在 GitHub Pages 仓库子路径下；本机双击 `index.html` 也能使用核心功能。

## 快速开始

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 在线使用 | 打开 GitHub Pages 地址 | 推荐；新闻快照由定时任务更新 |
| 本机使用 | 双击 `index.html` | 数据通过 `<script>` 加载，无需启动任何服务 |

详细步骤、发布与故障处理见 [docs/01-启动与发布.md](docs/01-启动与发布.md)。

## 七个模块

1. **企业研究档案**：小熊电器、石头科技两家企业档案（产品、研究市场、原始来源、关键已知事实、待核实参数），可一键带入产品登记。国内型号不自动当作出口型号。
2. **产品与市场登记**：57 个叶子小类按品类动态生成问题（功率、容量、供电、无线、电池、食品接触、地区版等）；允许回答「不确定」，并说明哪些判断因此无法完成。
3. **法规与合规初筛**：条件规则三值引擎（可能适用 / 单条规则不适用 / 待补事实 / 待规则核验），生成办理行动、材料清单与责任建议；覆盖不足时明确显示缺口。
4. **HS 与税费**：目的国 HS 候选方向（非海关最终归类）；SG/AU 已核税费画像按公式逐行输出税基、税率、税额、币种与承担方；关键条件缺失时完整总额保持为空并说明原因。
5. **政策与新闻雷达**：政府官方 RSS/Atom 快照（GitHub Actions 定时采集，北京时间约 09:17 / 17:17），支持市场、主题、关键词与当前项目筛选，可勾选进入分析任务。
6. **千问辅助建议**：无付费 API 的手动闭环——生成带证据的分析任务 → 复制交给千问办公 → 把真实回复粘贴回本页保存合并；明确区分「规则提示（本地引擎）」与「千问回复（人工导入）」，输入变化后旧建议标记需要重新分析。
7. **综合报告**：汇总企业、产品、目的地、合规结果、行动材料、税费、新闻与千问建议，每项结论可追溯到来源；支持打印/导出 PDF、导出项目 JSON、报告快照（历史结果标记）与本机保存（单机，非多人协作）。

## 目录结构

```
├── index.html              # 主页面（单页应用）
├── css/styles.css          # 样式
├── js/engine.js            # 三值规则引擎 + SG/AU 税费引擎（语义与原始数据包一致）
├── js/app.js               # 七大模块与项目状态（localStorage 本机保存）
├── data/vo-data.js|json    # 整合数据包（由 build/build-data.mjs 生成）
├── data/news.js|json       # 新闻快照（由 tools/collect_news.py 定时重建）
├── news/feeds.json         # 新闻 RSS/Atom 来源配置
├── tools/collect_news.py   # 新闻采集与合并（Python 标准库）
├── tools/rebuild_news_js.mjs  # 无 Python 环境时重建 news.js 的辅助脚本
├── build/build-data.mjs    # 从原始团队交付物生成数据包的构建脚本
├── .github/workflows/update-news.yml  # 定时新闻采集工作流
├── tests/                  # 引擎回归（208 断言）、DOM 冒烟（48 断言）、静态资源（25 断言）
└── docs/                   # 中文文档（启动发布、产品介绍、演示脚本、数据来源、测试与验收记录）
```

## 数据快照与边界

- 原始数据快照：**2026-11-04**（整合构建 2026-11-05）
- 规则引擎：86 条条件规则；产品小类 57 个；法规索引 79 条；来源记录 284 条；行动 65 / 材料 137；HS 候选 61 条；税费画像 SG/AU 共 8 个
- 覆盖等级：L3（可复算主路径）仅 SG×电热水壶、SG×烤面包机；其余组合按 L2/L1 如实展示缺口
- 本工具用于合规准备与资料组织，不构成正式合规、认证、法律、税务、原产资格或海关归类结论
