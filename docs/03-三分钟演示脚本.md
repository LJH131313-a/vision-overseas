# 三分钟演示脚本

> 建议顺序：把页面投屏，按下面 8 步走。括号内是每步停留时间。

## 0. 开场（15 秒）

「中国企业把小家电卖到海外，最先卡住的不是设计也不是渠道，而是‘这台产品进了那个国家，到底要办什么、交多少税、依据是什么’。远见·企业出海助手把企业研究、产品参数、法规、税费、官方公告连成一条可追溯的流程。」

## 1. 企业研究档案（30 秒）

- 打开第 1 步「企业研究档案」：小熊电器、石头科技两家档案。
- 指出三点：**已核参数**（如 DFB-P20H1 电饭煲 600 W / 220 V / 3 L）、**待核实参数**（最大煮饭容量、出口插头）、**研究路线声明**——「这是研究路线，不是已经实现的出口事实」。
- 点击「带入产品登记」→「页面自动跳到第 2 步」。

## 2. 产品与市场登记（35 秒）

- 指出目的地与产品小类：小类是 57 个叶子类之一，证据等级 M1/M2/M3 如实显示。
- 演示**不同品类不同问题**：切到「扫地／扫拖机器人」，问题列表立刻变成电池、无线、联网、基站相关。
- 演示**不确定**：把一项答成「不确定」，底部摘要提示「对应判断保持待确认，不会按否处理」。

## 3. 法规与合规初筛（40 秒）

- 进入第 3 步（可先切目的地为德国），点「运行条件初筛」。
- 讲四类结果：**可能适用**（含需人工复核）、**单条规则不适用**（每条有原因）、**待补事实**（现场点一个「是」，结果立刻刷新）、**待规则核验**（索引级法规不冒充可执行规则）。
- 指出覆盖横幅：L2「条件初筛」的含义；行动与材料清单带责任建议和完成节点。

## 4. HS 与税费（40 秒）

- 德国组合：显示「无目的国 HS 候选」的**明确缺口**——「没有数据就不给数」。
- 新建/切换到新加坡 × 电热水壶（L3 主路径）：选中 HS 85167910，填货值 20000、运费 1500、保险 100，点「计算税费」。
- 讲结果表：税基、税率、税额、币种、承担方逐行输出；**贸易救济未核查 → 完整总额保持不可用**，原因列在红框里；指示性操作费不计入法定小计。

## 5. 政策与新闻雷达（25 秒）

- 打开第 5 步：快照更新时间、来源状态表（成功/失败如实显示）。
- 说明边界：「官方公告定时快照，不是实时监控，也不做社交平台情感监测；官方新闻不自动等于已生效法规。」
- 勾选 1–2 条当前项目目的地的新闻。

## 6. 千问辅助建议（30 秒）

- 第 6 步点「根据当前项目生成分析任务」：任务里带企业、事实、初筛结果、税费缺口和所选新闻，并要求按「已知事实/适用前提/待补资料/优先行动/责任角色/引用依据 + 立即办理/补证后判断/持续关注」输出。
- 点「复制任务」→「我们把任务交给千问办公分析」，把真实回复粘贴回文本框保存。
- 指出标注：回复标记为「千问回复（人工导入）」；页面里的规则提示是「本地引擎」，两者分开。

## 7. 综合报告（20 秒）

- 第 7 步：报告汇总全部结论，每条带来源与指纹；点「保存报告快照」→ 再改一个输入 → 报告顶部立即显示「快照为历史结果」。
- 点「打印 / 导出 PDF」和「导出项目 JSON」。

## 8. 收尾（10 秒）

「规则引擎的 208 项断言来自原始数据包的 38 个业务测试案例；数据快照 2026-11-04；新闻由 GitHub Actions 每天两次定时更新。没覆盖的组合，我们显示缺口，不编结论。」
